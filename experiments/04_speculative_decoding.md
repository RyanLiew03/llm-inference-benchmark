# 实验 04：投机解码 (Speculative Decoding) 实测

## 1. 实验背景
测试投机解码在 vLLM 中的实际加速效果。

## 2. 实验配置
- 目标模型：Qwen2-0.5B-Instruct
- Draft 模型：Qwen2-0.5B-Instruct
- 猜 token 数：5

## 3. 实验数据
- 平均接受率 (Acceptance rate)：24.3%
- 平均接受长度：2.22
- 生成吞吐量：5.0 tokens/s（无投机解码也是 5.0）

## 4. 结论
- 投机解码没有加速。原因：Draft 和 Target 模型同尺寸，导致接受率太低（只有 24.3%）。
- 接受率随位置递减（第1个位置 60.9%，第5个位置 8.7%）。
- 真正的投机解码必须是“小模型猜，大模型验”。后续需替换 Draft 为更小的模型。
